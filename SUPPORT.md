# Support

Start with the [README](README.md), [known defects](ISSUES.md), and
[validation limitations](VALIDATION.md). Setup requires Python 3.12 or later;
the README explains the locked development install and how to run the app.

For questions or reproducible bugs, use
[GitHub issues](https://github.com/mickpletcher/bookmark-xport/issues).
For accessibility barriers, see [ACCESSIBILITY.md](ACCESSIBILITY.md).
For security issues, follow the private route in [SECURITY.md](SECURITY.md).

Include your OS, Python version, application version or commit, expected and
actual behavior, and a minimal synthetic reproduction. Redact logs and
screenshots. Never attach browser profile files, databases, real bookmark
exports, credentials, or personal paths. Support is community-based; no response
time or resolution guarantee is made.
